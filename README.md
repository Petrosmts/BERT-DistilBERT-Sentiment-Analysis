# BERT & DistilBERT Sentiment Analysis

A Natural Language Preprocessing (NLP) project exploring transformer-based models for sentiment classification using **BERT** and **DistilBERT**.

## Overview

This project focuses on implementing and evaluating sentiment classification using two pretrained transformer models, BERT and DistilBERT, fine-tuned for sentiment analysis. Using Hugging Face Transformers and PyTorch, the project explores how these models can be applied to text classification and compares their performance.

## Objectives

- Apply pretrained BERT and DistilBERT models to sentiment classification.
- Experiment with different hyperparameter configurations to improve model performance.
- Evaluate model performance using Accuracy, Precision, Recall, and F1-score.
- Compare BERT and DistilBERT based on their performance under different hyperparameter settings.

## Project Workflow

1. **Data Preparation** — Load and preprocess the text data.
2. **Tokenization** — Convert text into model-compatible token representations.
3. **Model Setup** — Load the pretrained BERT and DistilBERT models for sentiment classification.
4. **Training / Fine-tuning** — Train or fine-tune the models on the selected dataset.
5. **Evaluation** — Evaluate the models using Accuracy, Precision, Recall, F1-score, and ROC-AUC.
6. **Comparison** — Examine the results and differences between the two models.
