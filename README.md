# BERT & DistilBERT Sentiment Analysis

A Natural Language Preprocessing (NLP) project exploring transformer-based models for sentiment classification using **BERT** and **DistilBERT**.

## Overview

This project focuses on implementing and evaluating sentiment classification using two pretrained transformer models, BERT and DistilBERT, fine-tuned for sentiment analysis. Using Hugging Face Transformers and PyTorch, the project explores how these models can be applied to text classification and compares their performance.
